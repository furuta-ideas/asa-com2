# あさちゃんコミュニケーションボード 手書き版 ＜Asa-Com2＞

**文字認識を行わず、書いた筆跡をそのまま伝える手書きボードです。**
単一HTML・外部依存なし・オフライン動作。2026-11-15 更新（Rev.15）。

## 公開URL

[Asa-Com2を開く](https://furuta-ideas.github.io/asa-com2/)

## 使いかた

1. 最初の案内をタッチして開きます。
2. 左側の面に、指・ペン・マウスで自由に書きます。文字、絵、複数行の文章も書けます。
3. 画面下部の大きな **「確定」** を押します。
4. 右側の「確定した手書き」に、筆跡の形・線の太さ・配置を保ったまま追加されます。左側は次の入力用に空になります。

確定した筆跡は順番に並び、幅に収まらない記録は次の行に折り返します。ひとつの確定内容が大きい場合も、縦横比を保って全体を表示します。記録が増えたら右側をスクロールしてください。

- **一画もどす**：未確定の線を最後の一画だけ取り消します。
- **書き直す**：未確定の手書きを消します。確定済みの記録は変わりません。
- 丸・濁点・ジグザグも普通の筆跡として残します。自動確定・候補表示・文字への変換はしません。
- 「操作を声で知らせる」では操作案内だけを読み上げます。手書きの内容は読み上げません。

## 記録と設定

右上の設定から、線の太さ・ハイコントラスト・操作音声を変更できます。
記録は使用中のブラウザーのlocalStorageに保存し、再読み込み後も表示します。旧版の文字認識で保存したテキスト記録も表示できます。

**「記録を書き出す（JSON）」** で全記録の座標・線の太さ・日時を保存できます。ブラウザーのデータ削除や端末変更の前に書き出してください。保存容量不足などで記録できない場合は、元の手書きを消さずにエラーを表示します。右側への確定は保存成功後に行います。

## iPadで使う

Safariで公開URLを開き、共有メニューから「ホーム画面に追加」すると全画面で使えます。
画面上部の更新日時が **2026-11-15** 以降になっていることを確認してください。古い画面が残る場合はSafariでページを再読み込みしてください。
指で直接書く場合はVoiceOverをOFFにしてください。文字を聞いて確認する旧版の操作とは異なります。

## 開発・確認

- 'index.html'：配布するアプリ。文字認識エンジンや学習済みモデルは含みません。
- 'SPEC.md'：現行Rev.15の仕様と、それ以前の仕様履歴。
- 'test/manual.test.js'：確定、原筆跡の保存・復元、保存失敗、折り返し、回転、6画面サイズの回帰テスト。
- 'test/browser.js'：Node.jsの標準機能だけで動くChrome/Edge用テストクライアント。
- 'tools/stamp.js'：画面に表示する更新日時を書き換えます。
- 'training/'：旧版の文字認識研究用の履歴資料です。現行アプリでは使用しません。旧版の実行環境はGit履歴を参照してください。

Node.js 22以降とChrome・Edge・Chromiumを使って実行します（Playwright等の追加依存は不要）。

```sh
node test/manual.test.js
node test/recognize.test.js
node tools/stamp.js
```

ブラウザーが自動検出されない場合は環境変数 'CHROMIUM_PATH' に実行ファイルを指定してください。
旧来の 'test/e2e.test.js'・'test/layout.test.js'・'test/speech.test.js' も現行の回帰テストを実行します。
