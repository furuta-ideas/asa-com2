# あさちゃんコミュニケーションボード 手書き版 ＜Asa-Com2＞

iPad の画面に**指で1文字ずつカタカナ・数字を書く**と、読み取った文字をその場で**女性の声**で発音し、
「。」を書くと**文全体を読み上げてログに残す**意思伝達（AAC）アプリ。
**単一 HTML ファイル・外部依存なし・オフライン動作**。

| ファイル | 役割 |
| --- | --- |
| `index.html` | 配布物。これ1つで動作します（学習済みモデルも内蔵） |
| `SPEC.md` | 仕様書（Rev.8） |
| `test/recognize.test.js` | 認識エンジンの自動テスト |
| `test/speech.test.js` | 音声が出るかのテスト（iPadOS の制限を再現） |
| `test/e2e.test.js` | 画面の通しテスト（要 Playwright） |
| `training/` | 認識モデルを作り直すための学習スクリプト一式 |
| `tools/stamp.js` | 画面に出す更新日時を書き換える（リリース前に実行） |
| `docs/screen-sketch.jpg` | 元になった画面設計図 |

## 使いかた（本人）

**画面が見えなくても、耳だけで使えます。左半分はどこに・どんな大きさで書いても構いません。**

| やること | 書きかた | 返ってくる合図 |
| --- | --- | --- |
| 文字を入れる | カタカナか数字を**1文字だけ**書く | 「ア」のように1文字を読み上げ＋高い音 |
| 濁音にする | 書いた文字のすぐあとに、**小さく「゛」**（点2つ）を書く | 「ガ」と読み上げ |
| 半濁音にする | ハヒフヘホ のあとに、**小さく「゜」**（小さな丸）を書く | 「パ」と読み上げ |
| のばす音 | **横線を1本**（ー） | 「ノバス」 |
| 1文字消す | **ジグザグ**を大きく書く（折り返し3回以上） | 「削除」＋低い音 |
| 文を伝える | **小さな丸**（。）を書く | 上がる2音のあと、**文全体を読み上げ** → ログに残って行は空になる |

- 読み取れないときも、**いちばん近い字に寄せて**必ず読み上げます（違っていたらジグザグで消すか、
  介助者が候補ボタンで直せます）。設定で OFF にすると「認識できません。」と言うようにもできます
- 「パ」と聞こえたけれど「。」のつもりだった → **もう一度小さな丸**を書けば「ハ」に戻して文を確定します
- 書きかけの字を捨てたいときも**ジグザグ**でかまいません

## 使いかた（介助者）

右の列に、本人が使わない予備のボタンがまとまっています（本人が書く左半分にはボタンがありません）。

| 場所 | できること |
| --- | --- |
| 上の帯 | 本人が書いた**筆跡そのもの**と、読み取った文字が並びます |
| 　└ 色の見かた | **大きい黒＝書いた筆跡** ／ **小さい青＝読み取った文字** ／ **小さいオレンジ＋下線＝読み取ったが自信が低い**（確認してください） |
| 候補ボタン（右） | 読み間違いのとき「ソ にする」を押すと直前の1文字を差し替えます（4秒表示・設定で変更可） |
| ゛ ゜ ー 。 けす よみあげ | 手書きと同じことをボタンでも行えます |
| 🔊 / 📝 | 読み上げ・ログの ON / OFF |
| 右上 ⚙ | 設定 |

## はじめかた

1. iPad の Safari で上記URLを開く（またはこの `index.html` を直接開く）
2. 共有メニュー → **ホーム画面に追加** でフルスクリーン起動になります
3. 最初の画面（**つかいかたが書かれた画面**）をどこでもよいので1回タッチしてください。
   「じゅんびが できました。かいて ください。」と聞こえたら準備完了です
   （iOS の制限で最初の操作までは音が出ないため、アプリ側で読み上げを自動的に入れ直しています）

### iPad 側でお願いしたい設定

| 項目 | 設定 |
| --- | --- |
| **VoiceOver** | **OFF**（ONだと画面に指を置いても線が描けません。案内はアプリ自身の声で行います） |
| 音量 | 本人に聞こえる大きさに |
| 誤ってアプリを抜けないように | 設定 > アクセシビリティ > アクセスガイド（使用中の固定を推奨） |

## 入力できる文字

- カタカナ 46字（ア〜ン）＋ 長音「ー」
- 濁音・半濁音（ガ〜ポ）… 文字のあとに小さく「゛」「゜」
- 算用数字 0〜9
- 句点「。」＝ 文の終わり

※ ひらがな・漢字・アルファベット・小書き（ャュョッ）・空白・読点は、この版では入力できません。

## よく間違える字があるとき（おぼえさせる）

本人の書きぐせは人それぞれなので、**その字を覚えさせる**のがいちばん確実です。

| やりかた | 手順 |
| --- | --- |
| ①直したときに覚える（自動） | 読み間違いを**候補ボタン**で直すだけ。その筆跡を「本当はこの字」として覚えます（既定ON） |
| ②まとめて教える | ⚙ → **手書きを おぼえさせる** → 字を選ぶ → 本人が**3回**書く（「◯◯を かいて ください」と声で案内します） |

覚えた筆跡とよく似た字が来たら、その字を最優先で選びます。
⚙ の「**おぼえた字を 書き出す**」で JSON に保存でき、別の iPad へ移したり、開発側に渡して
認識モデルの改善に使ったりできます。

## 設定でできること

右上の ⚙ から調整できます（本人が誤って開いてしまう場合は「設定ボタンを長押しで保護」をON）。

| セクション | 調整できること |
| --- | --- |
| 書く・読み取る | **書き足し待ち時間（既定400ms）**、早く確定する、読み取りのきびしさ、読めなくても近い字にする、**数字をつかう（既定OFF）**／数字だけモード、候補を出す時間、ジグザグの判定、線の太さ、マス目ガイド |
| おぼえさせる | おぼえた字をつかう、まちがいを直したら おぼえる、カタカナを数字より優先、手書きを おぼえさせる、書き出し／読み込み／消去 |
| 画面 | 文字サイズ、ログ欄の幅、介助者用ボタンの表示、ハイコントラスト |
| 音 | 読み上げ ON/OFF、**声を選ぶ**、速度、高さ、効果音、指が触れたら小さな音、「認識できません」を言う、「けすものが ありません」を言う |
| ログ | ログを記録する |
| その他 | 使用中は画面を消さない、設定ボタンを長押しで保護 |

- **うまく読み取れないとき**：数字を使わない場面では「数字をつかう」をOFFにすると精度が上がります
- **起動しても声が出ないとき**：まず画面をもう一度タッチしてください（触れるたびに立ち上げ直します）。
  5秒たっても鳴らなければ画面上部に「**音が出ていません**」の帯が出ます。［音を出してみる］を押すか、
  ⚙ →「**音が出ないときの点検**」を開いてください。4通りの方法でテスト発話ができ、
  端末の声の一覧・エラーの理由・できごとの履歴が読めます（［点検の結果をコピー］で共有できます）
- **「認識できません」と言われるのが煩わしいとき**：「読めなくても いちばん近い字にする」を ON（既定）に。
  逆に、当てずっぽうで読み上げてほしくないときは OFF にしてください
- **書き終わる前に確定してしまうとき**：「書き足し待ち時間」を長く（既定は 1000ms）
- **声が出るまで待たされるとき**：「書き足し待ち時間」を 200〜300ms に
- **声が出ないとき**：起動画面を1回タッチすると「じゅんびが できました」と鳴ります。鳴らない場合は
  iPad の消音スイッチ・音量・（設定の）読み上げ ON をご確認ください

## 画面に出ている更新日時

ヘッダーと起動画面の右に「**更新 YYYY-MM-DD HH:MM**」（日本時間）が出ます。
iPad に古い版がキャッシュされていないかは、ここを見て確認してください。

- 表示が古いまま → Safari で開き直す、またはホーム画面のアプリを一度閉じて開き直してください
- 変更を公開するときは、コミット前に更新日時を打ち直します

```bash
node tools/stamp.js            # 現在時刻（日本時間）にする
node tools/stamp.js "2026-09-23 09:00"   # 時刻を指定する
```

## データの扱い

- 設定・ログは端末内（`localStorage`）にのみ保存され、外部へ送信されません
- 設定 > **ログを書き出す（CSV）** で `asacom2_log_YYYYMMDD.csv` を保存できます
- 文字認識・音声合成とも端末内で完結し、通信は一切行いません

## 認識エンジンについて

**2つの見方を組み合わせて**判定します。どちらも端末の中だけで動き、通信は一切しません。

| | 見るもの | 得意なこと |
| --- | --- | --- |
| 筆画マッチング | 画の本数・順番・向き・通った道すじ | `ソ`/`ン`、`シ`/`ツ` など**向きでしか区別できない字** |
| CNN（機械学習） | 書き上がった**形**（48×48の画像） | **画をつなげた／切った／筆順が違う**字、位置や大きさのずれ |

最終判定は「CNN 0.72 ＋ 筆画マッチング 0.28」の重み付けです。
CNN は当アプリ専用に学習させた小さなモデル（約5万パラメータ）で、**重みを `index.html` に内蔵**しています
（約67KB）。外部サービスやCDNからのダウンロードはありません。

### 効果（自動テストの実測・同じ筆跡で比較）

| 書き方 | 筆画マッチングのみ | CNNのみ | **併用（現在）** |
| --- | --- | --- | --- |
| ふつうに書く | 98.0% | 99.2% | **99.9%** |
| 筆順を逆にする | 96.5% | 99.2% | **99.4%** |
| 画を逆向きに書く | 91.1% | 99.4% | **99.6%** |
| 画をつなげて書く | 24.3% | 89.9% | **87.9%** |
| 画を途中で切る | 1.3% | 99.5% | **99.5%** |
| 合計 | 62.2% | 97.4% | **97.3%** |

指で書くと画がつながったり切れたりしますが、以前の方式（筆画マッチングのみ）はそこで大きく崩れていました。
これが実機で「精度が悪い」と感じられた主な原因です。

- `フ`/`7`、`コ`/`ユ` のように字形がほとんど同じ組は取り違えが残ります。候補ボタンでの訂正、
  または「数字をつかう」OFF で回避してください
- モデルを作り直す手順は `training/README.md` にあります
